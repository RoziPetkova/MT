## Preparation (all experiments)

**RT trimming**
- Run SPSS script (2w.SPS): cuts per sub × w1 × w2 at mean ± 2 SD (strict inequality)
- Record: N trials before / after / % removed
- Subject-level outlier check: exclude if subject's overall mean RT > grand mean + 2 SD
  - Same criterion applied in all three experiments

**Likert exclusions**
- Flag if dominant response > 75% of all trials
- Exclude if flagged AND condition range ≤ 0.5 (no discrimination between conditions)
- Keep if flagged but range > 0.5 (still differentiates conditions)
- This goes in the **Method / Participants** section, not Results

## Analysis 1 — Main rANOVA per experiment
**2 (gaze congruency: congruent / incongruent) × 3 (action consistency: consistent / inconsistent / control)**
**DV: mean RT per sub × condition cell**
**Addresses: RQ1a**

**How:**
- Aggregate to mean RT per sub × w1 × w2 (from SPSS-trimmed data)
- Run in pingouin: `pg.rm_anova(dv='rt_mean', within=['w1','w2'], subject='sub')`
- Apply Greenhouse-Geisser correction if Mauchly's test significant (pingouin does this automatically)
- Follow up significant effects with Bonferroni-corrected pairwise comparisons

**What to report:** F, df, p, η² (or partial η²) for each effect; means and SDs per cell

**Outcomes and interpretation:**

| Result | Interpretation |
|--------|---------------|
| Interaction w1 × w2 significant | AOC modulates the GCE → core finding, run post-hoc |
| Main effect w1 (gaze) only, no interaction | GCE is present but not modulated by AOC → null for RQ1a |
| Main effect w2 (action) only | RT differs by AOC condition regardless of gaze direction → not a GCE modulation |
| Neither significant | Null result across the board → see fallback interpretation in structure.md 6.5 |

**Post-hoc if interaction significant:**
- Bonferroni pairwise on the w1 × w2 cells
- Key comparisons: congruent vs. incongruent within each AOC condition (= GCE per condition)
- Expected pattern: GCE(consistent) > GCE(control) > GCE(inconsistent)
- If GCE(inconsistent) is negative (reversed): this is a strong finding — see Analysis 1b

## Analysis 1a — GCE in the control condition
**Is there a standard gaze cueing effect when participants did NOT cause the gaze?**
**This analysis has NOT been run yet — needs to be done.**

**Why this matters:**
- The control condition is the closest thing in this paradigm to a standard gaze cuing experiment (no action, gaze appears on its own)
- If GCE is absent in control, it cannot simply be explained by higher RT variance in that condition — but this can be tested

**How — Step 1: extract GCE in control from the main rANOVA**
- From post-hoc or simple effects: compare congruent vs. incongruent RT within the control condition only
- Also compute GCE size (incongruent − congruent) per experiment for each condition → use for 6.1 overview table

**How — Step 2: if GCE absent in control, run the variance-reduction retest**
- Take only control-condition trials from the trimmed dataset
- Re-trim within control only: per sub, remove trials > mean ± 2 SD (this removes the extra variance that control trials accumulate because there's no directional expectation priming the participant)
- Run paired t-test or 1-way: congruent vs. incongruent on the re-trimmed control-only data
- If GCE now appears → variance was the explanation; note in Results and Discussion

> 📌 **Ask Armina:** Is Step 2 necessary at all, or is it overkill? The main rANOVA already uses trimmed data; doing a second round of trimming specifically for control trials is an additional step that may not be methodologically standard. Armina may know a simpler or more accepted way to address the variance argument (e.g., reporting the RT variance per condition descriptively as evidence, without re-trimming).

**Outcomes and interpretation:**

| Result | Interpretation |
|--------|---------------|
| GCE present in control (both steps) | Normal baseline; action conditions show modulation above/below this baseline |
| GCE absent in step 1, present after re-trim (step 2) | Higher RT variance in control suppressed the effect; note this as a methodological artefact; variance explanation holds |
| GCE absent even after re-trim | **Cannot be explained by variance.** Requires a theoretical explanation — see below |

**If GCE is absent in control even after variance cleaning:**

This is theoretically the most interesting outcome. Possible explanations (discuss in 6.2 and 6.5):

1. **Paradigm context effect:** Participants have learned throughout the experiment that gaze is something they cause. In control trials, the gaze is not caused — they may implicitly discount it as a social directional signal, reducing its attentional capture. The AOC context changes the meaning of the gaze cue globally.

2. **Credibility / contingency:** In standard gaze cuing, the gaze is unambiguously a social cue from an agent. In this paradigm, the control gaze is "random" relative to the participant's actions. Participants may partially treat it as noise rather than a socially meaningful directional signal.

3. **Attentional priming by action:** In action conditions, participants have just made a deliberate directional decision. This directional priming may amplify gaze cue processing. In control, no such priming exists, so the gaze cue receives no attentional boost from prior action.

4. **If GCE absent in control across all three experiments:** This would suggest that, in this paradigm, a gaze cue only effectively orients attention when it has been caused by the observer's action. This would be a strong secondary finding — it inverts the normal framing and suggests action-causation is necessary (not just sufficient) for social attentional orienting in this context.

> 📌 **Note on the pilot:** Armina noted GCE was present in control in the pilot because the task was more difficult (more cognitive load → less top-down suppression of gaze following). If GCE is absent in the main experiments, difficulty/load differences between pilot and main study are a relevant comparison point.

## Analysis 1b — Reversed GCE in inconsistent condition
**Optional interpretation note — no separate analysis needed, just a check of the post-hoc direction**

If GCE in the inconsistent condition is negative (mean RT: incongruent < congruent), this means participants are orienting *away* from the gaze direction — the opposite of normal gaze cueing.

**Interpretation:** Inconsistent AOC (action goes left, gaze goes right) creates an expectation violation. The observer expected the gaze to go in their action direction; when it goes the other way, their attention may be pulled toward the *expected* direction (where they intended) rather than the *actual* gaze direction. This would be a strong prediction-error effect.

**Where to discuss:** 6.2, and in each experiment's Discussion section. Flag it as a novel and theoretically important finding if observed.

## Analysis 2 — ANCOVA per experiment
**2 × 3 on RT with timing covariate**
**Removes temporal prediction component; isolates intentionality/volition**
**Addresses: RQ1 extension**

**Timing covariate — all three conditions are included:**

The covariate is structurally the same in all conditions: in both action and control trials, it represents "when the gaze starts to move," and the target always appears exactly 210 ms after that. The variable names differ by condition:

| Condition | Timing variable | Notes |
|-----------|----------------|-------|
| Consistent / Inconsistent | `SlideXeroA.RT` | When participant made their directional response |
| Control | `XeroDur` | Random delay (350–550 ms, E-Prime assigned) before gaze moves |

Combine into a single `timing_covariate` column before running ANCOVA.

> 📌 **Questions for Armina — resolve before running ANCOVA:**
>
> **Q1 — What does `SlideXeroA.RT` actually capture in Exp 2?** Is it the start of the mouse movement (when they began moving the cursor) or the moment of direction selection (when they clicked/reached the target zone)? This matters for what the covariate is removing. Exp 2 may also be missing this column entirely — check raw data and update procedure notes once confirmed. The same structural question applies to Exp 3 (touch = direction selection = end of movement; no separate movement start timestamp).
>
> **Q2 — Does it matter that the covariate is participant-driven in action conditions but externally set in control?** In action conditions, participants chose WHEN to act → they can predict target timing from their own action. In control, `XeroDur` is random → participants cannot predict it. Yet structurally, "gaze moves → 210ms → target" is true in both cases. Ask Armina whether this distinction affects the interpretation or whether it can be treated uniformly.

**How:**
- In pingouin (pg.ancova) or SPSS: timing covariate as covariate, w1 and w2 as within factors
- Compare results to main rANOVA (Analysis 1)

**Outcomes and interpretation:**

| Result | Interpretation |
|--------|---------------|
| Effect remains significant after ANCOVA | Intentionality (directional matching) drives the AOC effect, not just temporal prediction |
| Effect weakens but remains | Both temporal prediction and intentionality contribute |
| Effect disappears | Temporal prediction (knowing *when* the target arrives) was the primary driver; AOC effect is a timing artefact |

> 📌 **Post-hoc for Exp 1 (flagged as missing from existing analysis):** Run pairwise comparisons on the ANCOVA-adjusted means across the 2 × 3 cells. Expected: congruent-consistent should be fastest (gaze + intentionality both aligned). If confirmed: intentionality and gaze cue combine additively (or synergistically) to orient attention.

**Outcomes and interpretation:**

| Result | Interpretation |
|--------|---------------|
| Main effect of action consistency only | AOC manipulation worked; all three SoA aspects differentiate equally |

- This is theoretically important: it means consistent vs. inconsistent AOC does not affect all dimensions of SoA equally
- Example: if "caused" ratings differ strongly between conditions but "predict" ratings do not → causal attribution changes across AOC conditions but prospective prediction does not
- Example: if "control" ratings are flat but "caused" varies → volition is not the sensitive dimension; retrospective causal attribution is
- Discuss in 6.4 — this decomposition tells you which component of explicit SoA is being manipulated by AOC

## Analysis 4 — Bin analysis (one experiment only)
**2 × 3 × 5 (gaze × action consistency × RT quintile bin) rANOVA**
**Addresses: RQ1b**

> 📌 **Ask Armina:** Run only for the experiment with the strongest main effect / interaction in Analysis 1. Do NOT run for all three by default — decide after all three experiments are complete and results are compared. Is running the bin analysis for only one experiment (the strongest) methodologically defensible? Or does it need to be run for all three to be comparable? 

> 📌 **Ask Armina:** The execution of this was discussed in one of the recordings — check the recording for her exact recommendation before conducting.

**How (replicating SPSS procedure):**
- Take SPSS-trimmed data for the selected experiment
- Within each sub × w1 × w2 cell, rank trials by RT and assign to quintile bins (NT5: 1=fastest 20%, 5=slowest 20%)
  - In SPSS: Transform → Rank Cases → Rank Type: Ntiles(5) → Variable: FilteredRT → By: sub, w1, w2
  - In Python: `df.groupby(['sub','w1','w2'])['FilterRT'].transform(lambda x: pd.qcut(x.rank(method='first'), 5, labels=[1,2,3,4,5]))`
- Aggregate mean RT per sub × w1 × w2 × bin
- Run 2 × 3 × 5 rANOVA

**Outcomes and interpretation:**

| Result | Interpretation |
|--------|---------------|
| AOC effect (or interaction) larger in early bins (bin 1–2) | Effect is automatic/reflexive — emerges in fastest responses, consistent with low-level prediction mechanism |
| AOC effect larger in late bins (bin 4–5) | Effect is controlled/top-down — only emerges when processing is slower, suggesting deliberate evaluation |
| AOC × bin interaction absent | Effect is uniform across RT distribution — does not distinguish automatic vs. controlled |

> 📌 **Armina's expectation:** stronger effects in early bins (faster responses affected more). If confirmed, supports the claim that AOC modulates a reflexive component of gaze cuing. This was discussed in one of the recordings — check recording for context before interpreting results.

## Analysis 6 — Correlation: initiation time × RT (exploratory)
**Run per experiment**

- Compute Pearson or Spearman r between initiation time (SlideXeroA.RT) and trial-level RT
- **Exp 1 result (from Armina's notes): no correlation found — flagged as unexpected by Armina**

> 📌 **Important — the direct logic is wrong:** RT is measured from target onset on a separate slide; initiation time does not add to it. "Longer decision time → longer RT" is not a valid direct mechanism. The correlation, if it exists, must be indirect. Possible mechanisms:
> 1. **Common trial-level state:** On more alert/prepared trials, participants act faster AND detect the target faster — the correlation reflects shared arousal/readiness, not a timing chain.
> 2. **Temporal precision of prediction:** Participants with more consistent action timing across trials can form a more precise temporal expectation of when the target arrives → better attentional readiness → faster RT. This would appear as a within-participant consistency effect, not necessarily a simple linear trial-level correlation.
> 3. **Motor-cognitive engagement:** A more "committed" trial manifests as faster action AND faster target detection because attention is more tightly coupled to the whole event.
>
> The absence of correlation in Exp 1 may be less surprising than it appears: keypresses are discrete and fast with low variability in initiation time — not much trial-level spread to correlate with RT. Exp 2 and 3 (continuous movements) have greater initiation time variability, so any of these mechanisms would have more room to manifest.

> 📌 **Ask Armina:** What is her explanation for why initiation time and RT *should* correlate? The logic cannot be that decision time adds to RT (different slides). What mechanism is she proposing, and does the absence of correlation in Exp 1 change her interpretation?

**Outcomes:**

| Result | Interpretation |
|--------|---------------|
| Positive correlation | Trial-level readiness or temporal precision links initiation time to RT — clarify mechanism with Armina |
| No correlation (as in Exp 1) | No shared trial-level factor linking action timing to target detection; consistent with RT being driven by gaze and intentionality, not action timing |
| Negative correlation | Faster action → slower RT? Unusual — check for outliers or floor effects |

> 📌 **Cross-experiment comparison:** If Exp 1 shows no correlation but Exp 2/3 do (more movement = greater initiation time variability = more room for the shared-state or temporal-precision effect to emerge), this would suggest that continuous motor actions create a stronger link between action timing and RT. Discuss in 6.2 and 6.5.
