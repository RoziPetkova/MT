Gaze × Experiment in the combined LMM: F(2,22458)=0.22, p=.804 (n.s.). Same conclusion in the plain mixed ANOVA on raw RT: F(2,135)=0.06, p=.939 (n.s.).

So the basic gaze-cueing effect itself — how strongly gaze direction speeds up target detection, independent of what action the participant did — is the same size whether the response was a keypress, a mouse click, or a touchscreen tap. Response modality doesn't touch the core reflexive-orienting phenomenon at all; it replicates cleanly across all three.

What response modality does touch is the interaction — how much the action-consistency manipulation (did your button press match, mismatch, or have nothing to do with the gaze shift) modulates that gaze-cueing effect. That's the Gaze × Action × Experiment term, marginal on raw RT (p=.061) and significant on log-RT/Cohen's d (p=.018/.013) — and it's specifically located in the inconsistent condition, Exp1 (keypress) vs Exp3 (touch).

So the story splits cleanly in two: the gaze-cueing effect is a stable, modality-independent phenomenon; whether your own action feeds back into how strong that effect is depends on how physically embodied the action is. That's a fairly clean theoretical distinction to have data support — the basic attentional mechanism doesn't care how you responded, but the self-monitoring/agency piece does.

Simple effects (what "GC effect by condition" is): used specifically to decompose an interaction. The question is "does Factor A's effect hold up within this one level of Factor B?" — you hold one factor fixed and test the other. This is the standard, expected follow-up when a 2-way interaction is significant (Exp2/Exp3 here) — you don't just report "the interaction is significant" and stop, you show where it lives. It's also legitimate (as exploratory, clearly labeled) to run even when the interaction isn't significant, as a descriptive check — which is what we did for Exp1.

Post-hoc tests: used to decompose a significant main effect that has 3+ levels, when you don't yet know which levels differ from which. E.g., if the Action main effect (3 levels: consistent/control/inconsistent) is significant, a post-hoc test (Holm, Tukey, Bonferroni) tells you specifically whether consistent differs from control, control from inconsistent, and consistent from inconsistent. This is about pinning down pairwise differences within one factor, not about how two factors combine.

One-way ANOVA: used when there's genuinely only one factor to test — either because the whole design only has one factor, or because you've deliberately restricted/sliced the data to isolate one specific comparison. We used this differently elsewhere: e.g., testing whether the size of the GC effect (already collapsed into one number per subject) differs by Experiment — that's a one-way ANOVA because at that point Experiment is the only factor left; the within-subject structure has already been reduced to a single per-subject value beforehand.
