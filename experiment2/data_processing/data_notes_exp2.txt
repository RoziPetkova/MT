   `SPSS_2w_script_bug_summary.txt` in the project root. Its last line, `FiltRT = filt*rt`, relies

   canonical for all three experiments now.

PIPELINE ARCHITECTURE (changed 2026-07-16)
==========================================================================
questions/pipeline.ipynb no longer reads anything from exp_data. It previously excluded exp_data's
low-accuracy subjects too (via a hardcoded list, `EXCLUDED = [1, 2, 45, 59]`) — this was removed:
accuracy can only be computed in exp_data anyway, and low-accuracy subjects naturally disappear
from the final merged analysis (Step 10's left join keeps only exp_data's subjects). Questions'
own final N is therefore larger now (53) than it used to be (49) — expected, not a regression.

The one thing that still flows between the two pipelines is the Likert exclusion — a whole-subject
judgment, so it removes RT data too, not just ratings. This is now a direct file: questions Step 03
writes `03_likert_excluded_subjects.txt`; exp_data Step 03 reads it directly (previously exp_data
recomputed the same dominant_%/range formula itself from the report — now centralized in one place).

ANCOVA COVARIATE
==========================================================================
09_initiation_time.xlsx: mean `initiation_time` (renamed from `timing_covariate` 2026-07-16;
SlideXeroA.RT) per subject, computed only across action trials (consistent + inconsistent) —
control trials use XeroDur (an arbitrary experimenter delay, not a real behavioral measure) and are
excluded from this average entirely. Merged into 10_questions_data_added.xlsx as
`mean_initiation_time`. Any ANCOVA using this covariate should itself be restricted to the 4
action-condition cells (cong_cons, cong_incons, incong_cons, incong_incons) — do not include the
*_ctrl columns in that analysis.
